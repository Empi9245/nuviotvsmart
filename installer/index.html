Nuvio TV for VIDAA OS

VIDAA web port • installation options vary by firmware

Recommended: Install with Sidee

On newer VIDAA TVs, use Sidee from a Windows computer on the same network. Pair with the PIN shown on your TV, then choose Install Nuvio. No TV DNS changes are required.

Sidee installation guide on GitHub →

Tested on VIDAA U09.60; compatibility varies by TV and firmware. The installer buttons below use the older browser API method.

Legacy browser installation requires TV permission

Installation Notes:
  • Method 1 (Universal Bookmark): Open the TV Internet Browser, go to your Nuvio URL, and bookmark it. The interface depends on its server; browser cache does not demonstrate a persistent local TV app.
  • Method 2 (Legacy Launcher Icon): On firmware that permits the browser API, clicking "Install to TV Launcher" requests registration of the current app URL. It does not copy Nuvio files to the TV. Permission, launcher availability and use after reboot must be verified separately.
